# Unleashed Recomp Android 0.6.0

This release fixes DLC installation on an existing game, improves mod settings compatibility, and adds a choice of game-storage location.

## Installation and storage

- **Add DLC without reinstalling the game** ([#162](https://github.com/SansNope/UnleashedRecomp-Android/issues/162)). Import DLC packages or a DLC-only ZIP/folder through the launcher, then launch the game to verify and install them. ZIPs staged by older builds are also handled. Packs are hash-checked before replacement, and interrupted replacements can recover the previous pack.
- **Choose where the game is stored** ([#90](https://github.com/SansNope/UnleashedRecomp-Android/issues/90)). Select internal storage or app folders on a mounted volume, including an SD card. Optional copying verifies the new files and keeps the original game, mods, settings and saves. A selected card must be available when launching the game; fully close and reopen the app before changing storage after a game session.

## Mod settings and translations

- **More HMM schemas work** ([#93](https://github.com/SansNope/UnleashedRecomp-Android/issues/93)). Mod settings accept trailing commas, comments and a UTF-8 BOM. Schema errors show a concise message instead of the complete file.
- Completed launcher translations in **English, Russian, German, Spanish, French, Italian, Japanese and Portuguese**, including mod settings, app updates, storage selection and installation errors.

## Gameplay and build fixes

- Fixed overlapping guest-memory copies with `memmove`, addressing ring crashes and broken collision triggers. Removed the earlier quarantine and collision repair workarounds ([PR #158](https://github.com/SansNope/UnleashedRecomp-Android/pull/158), **puopg**).
- Extended landscape rendering into the display-cutout area ([PR #153](https://github.com/SansNope/UnleashedRecomp-Android/pull/153), **vladector**).
- Restored the zstd CMake sources and executable permissions needed for fresh-clone builds ([PR #159](https://github.com/SansNope/UnleashedRecomp-Android/pull/159), **puopg**). Corrected host shader-tool configuration and shader-generation arguments.

Thanks to **puopg (Michael Chen)** and **vladector**, now listed in Credits, and everyone who tested builds and reported problems.

## Updating

Install `UnleashedRecomp_0.6.0.apk` over the existing app. The package ID and signing certificate match the previous release, so app data remains in place. The APK is an ARM64 Release build for **Android 10 or newer**, with version code **20**.

This build uses `main` at `4e19e48f` as its base. The **Adreno 8xx Experimental** driver profile and **POCO F8 Ultra low-latency** audio preset described in the published 0.5.3 release are absent from that source tree and are not included in this APK.
